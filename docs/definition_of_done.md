# Definition of Done (DoD) — Lab 7

## DoD — Requirement (REQ-###)
A requirement is considered "Done" when:
1. Possui ID único e título claro
2. Tipo definido (FR/NFR)
3. Stakeholder identificado
4. Descrição clara e sem ambiguidades
5. Critérios de aceitação definidos (2–4)
6. Impacto de variante identificado (quando aplicável)
7. Ligação a casos de uso ou funcionalidades
8. Método de validação definido (teste/demo/revisão)

---

## DoD — User Story (US-###)
A user story is considered "Done" when:
1. Tem ator e valor definido
2. É pequena e testável
3. Critérios de aceitação definidos
4. Implementação cumpre todos os critérios
5. Existem testes (unitários ou integração)
6. Não existem erros críticos
7. Está documentada (se necessário)
8. Foi validada pelos stakeholders
