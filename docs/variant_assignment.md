<h1>Atribuição de Variante — Equipe &lt;ETR-2026-Grupo-OsCria&gt;</h1>

<p>
Este trabalho usa o projeto EcoDoar como base de estudo. Atualmente, a plataforma está a ser desenvolvida para ambiente web, mas a proposta aqui é analisar como ela poderia ser adaptada para uma versão mobile.
</p>

<p>
O EcoDoar é uma plataforma digital que facilita a doação e reutilização de bens não perecíveis, ajudando a ligar quem doa a quem precisa, com apoio de instituições como a Cruz Vermelha. O sistema organiza doações, valida beneficiários e acompanha todo o processo até à entrega.
</p>

<p>
Neste estudo, não será feito o desenvolvimento real da aplicação nem escrita de código. O foco é apenas conceptual, no contexto da Engenharia Informática, analisando:
</p>

<ul>
    <li>Requisitos para uma versão mobile da plataforma;</li>
    <li>Possíveis funcionalidades;</li>
    <li>Formas de funcionamento;</li>
    <li>Estratégias de teste e validação.</li>
</ul>

<p>
O objetivo é compreender como um sistema já pensado para web poderia ser adaptado para dispositivos móveis, do ponto de vista do planeamento, requisitos e testes de software.
</p>
